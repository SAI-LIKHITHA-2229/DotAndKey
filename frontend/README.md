# Dot & Key: Frontend

React 19 + Vite single-page app. Setup, architecture and API docs are in the [main README](../README.md).

```bash
npm install
npm run dev      # http://localhost:5173
npm run lint
npm run build
```

Set `VITE_API_URL` in `.env` (see `.env.example`) if the API isn't at `http://127.0.0.1:5001`.
